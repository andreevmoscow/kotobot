# 🐱 Котобот: установка для новичков

Пошагово, с нуля. Займёт 10–15 минут.

**Что понадобится:**

- арендованный сервер (VPS) с Ubuntu — подойдёт самый дешёвый;
- доступ к нему: IP-адрес, логин `root` и пароль (всё это приходит в письме от хостинга);
- Telegram на телефоне или компьютере.

---

## Шаг 1. Зайти на сервер

Откройте терминал:

- **Windows:** нажмите `Win + R`, введите `cmd`, Enter.
- **macOS:** приложение «Терминал».
- **Linux:** любой терминал.

Введите команду (вместо `ВАШ_IP` — адрес сервера):

```bash
ssh root@ВАШ_IP
```

Нажмите Enter. Появится вопрос про отпечаток ключа — введите `yes` и Enter.
Затем попросит пароль. **При вводе пароля символы не видны** — это нормально,
просто вставьте пароль и нажмите Enter.

Если всё получилось, вы увидите строку вида `root@server:~#` — вы на сервере.

---

## Шаг 2. Скопировать одну команду

Скопируйте эту строку целиком и вставьте в терминал
(в Windows — правый клик мышью, в macOS/Linux — `Ctrl+Shift+V`):

```bash
curl -fsSL https://github.com/andreevmoscow/kotobot/archive/refs/heads/main.tar.gz | tar -xz && cd kotobot-main && sudo bash install.sh
```

Нажмите Enter. Начнётся установка: скачается проект, запустится мастер,
который задаст несколько вопросов.

Дальше идите по вопросам мастера — они простые.

---

## Шаг 3. Создать бота (когда мастер попросит токен)

Первый вопрос — «Каталог установки». Просто нажмите **Enter**.

Второй вопрос — **«Токен»**. Вот тут нужно создать бота:

1. Откройте Telegram и в поиске наберите **`@BotFather`** (у него синяя галочка).
2. Нажмите **Start** (или отправьте `/newbot`).
3. Он спросит имя бота — напишите любое, например `Котобот`.
4. Затем попросит username — он должен заканчиваться на `bot`,
   например `my_kotobot_bot`. Если занято — придумайте другой.
5. BotFather пришлёт сообщение с токеном вида
   `123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw`.
   Нажмите на токен, чтобы скопировать.
6. Вернитесь в терминал и вставьте его (символы не отобразятся) → **Enter**.

Мастер проверит токен и покажет имя вашего бота.

### Остальные вопросы мастера

| Вопрос | Что делать |
|---|---|
| Ключ TheCatAPI | Нажмите **Enter** — можно пропустить. С ключом будет больше лимит (10 000 запросов/мес), получить: thecatapi.com/signup |
| ALLOWED_CHAT_IDS | **Enter** — бот будет работать в любой группе, куда его добавят |
| Пауза между котиками | **Enter** (3 секунды) |
| Включить inline-режим? | **Enter** (да) |
| Подпись автора | **Enter** (1 — имя без уведомления) |
| Часовой пояс | **Enter** (Europe/Moscow) |
| Всё верно, ставим? | Введите `y` и Enter |

Если на сервере ещё нет Docker, мастер спросит разрешение на установку — ответьте `y`.

Дальше мастер соберёт и запустит бота — это 1–2 минуты.
В конце появится слово **«Готово»** и подсказки.

---

## Шаг 4. Разрешить боту читать сообщения в группе

По умолчанию Telegram скрывает от ботов сообщения в группах.

1. Снова откройте **@BotFather**.
2. Отправьте `/setprivacy`.
3. Выберите своего бота из списка.
4. Нажмите **Disable**.

Дополнительно, чтобы работал режим «наберите @бот в любом чате»:

1. `/setinline` → выберите бота → напишите `котик`.

---

## Шаг 5. Добавить бота в группу и проверить

1. Откройте свою группу → «Добавить участника» → найдите бота по username → добавьте.
2. Напишите в группе: `/cat`.

Должен прийти котик с кнопкой «🐱 Ещё котика».

> **Если бот молчит:** значит приватность не применилась. Удалите бота из группы
> и добавьте заново — после `/setprivacy` это обязательно.
> Ещё можно написать `/cat@ваш_бот` — так команда дойдёт в любом случае.

---

## Если что-то не получилось

| Проблема | Решение |
|---|---|
| `curl: command not found` | выполните `apt update && apt install -y curl`, затем повторите шаг 2 |
| `Permission denied` | команда должна начинаться с `sudo` — скопируйте её целиком |
| Бот не отвечает в группе | не выключена приватность (`/setprivacy` → Disable) или бота не добавили заново |
| «Котики сегодня прячутся 😿» | временно недоступны сайты с котиками — попробуйте через минуту |
| Забыли токен | @BotFather → `/mybots` → ваш бот → **API Token** |

---

## Полезно знать

- **Как обновить бота:** снова выполните команду из шага 2 — она поставит свежую версию.
- **Где логи:** `cd /opt/kotobot && docker compose logs -f` (выход — `Ctrl+C`).
- **Как ограничить одной группой:** см. раздел «Управление группами» в
  [README](README.md) — там команды `/allow`, `/deny`, `/chats`.
  Чтобы они заработали, впишите свой Telegram id в `OWNER_IDS` (id показывает команда `/whoami`).
- **Токен — это пароль от бота.** Никому не пересылайте. Если он утёк —
  в @BotFather сделайте `/revoke` и получите новый.
